# Бизнес-правила

## Задачи

- Задача может быть создана без проекта.
- Если задача связана с проектом, она может принадлежать только одному проекту.
- У задачи всегда есть автор.
- Исполнитель задачи необязателен.
- У задачи всегда есть статус и приоритет.
- При создании задачи устанавливается начальный статус  `backlog`.
- При создании задачи создаётся первая запись в Журнале событий.

## Проекты

- Проект может существовать без задач.
- Пользователь, создавший проект, автоматически становится участником проекта.
- В рамках одного проекта пользователь имеет одну роль.

## Теги

- Одна задача может иметь несколько тегов.
- Один тег может использоваться в нескольких задачах.
- Один и тот же тег нельзя добавить к одной задаче повторно.

## Журнал событий

- Журнал событий ведётся только по задачам.
- Каждая запись журнала относится к одной задаче.
