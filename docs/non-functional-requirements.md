# Нефункциональные требования

- API возвращает ответы в формате JSON.
- Все защищённые методы требуют авторизацию пользователя через Bearer токен.
- Ошибки возвращаются в едином формате.
- Операции создания ресурсов должны поддерживать идемпотентность через заголовок `Idempotency-Key`, для избежания дублей при повторном запросе.
