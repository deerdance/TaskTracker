# Status model

## task

| Статус | Описание |
|---|---|
| backlog | Задача создана. |
| analysis | Задача в аналитике. |
| in_progress| Задача в разработке. |
| testing | Задача на тестировании |
| ready_to_release | Задача готова к выводу на продуктивный контур. |
| released | Задача выведена на продуктовый контур. |
| trashed | Задача перемещена в корзину. |

## project

| Статус | Описание |
|---|---|
| new | Проект создан. |
| analysis | Проект в аналитике. |
| in_progress | Проект в разработке. |
| done | Проект завершён. |
| cancelled | Проект отменён. |

## notification

| Статус | Описание |
|---|---|
| new | Уведомление создано системой, но ещё не отправлено. |
| sent | Уведомление передано на отправку. |
| delivered | Пользователю доставлено уведомление. |
| failed | Уведомление не удалось обработать или доставить. |
